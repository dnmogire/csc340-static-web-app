About This Project

This is a static website prototype built for a class assignment. It focuses on a Manchester United themed player gallery and demonstrates the basics of multi-page navigation, layout, and simple JavaScript interactivity.

What this site demonstrates

This project is intentionally “static,” meaning there is no server, no database, and no login. Everything loads instantly from simple files (HTML, CSS, and JavaScript). That makes it perfect for GitHub Pages.

  • Home gallery: 5 players with summaries and a search bar filter.
  • Details page: deeper profile data for one player and quick links to other pages.
  • About page: longer explanation and a theme image for a more realistic website feel.
  • Form page: inputs for all player details (like a real submission form).

If this were upgraded later, the form could send data to a database and the gallery could pull player information from an API. For this assignment, the goal is clean structure, readability, and deployment success.
