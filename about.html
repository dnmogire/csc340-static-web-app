About This Static Web App

This project is a prototype static website for a fictional character gallery. It uses only HTML, CSS, and JavaScript—no databases or servers—so it runs perfectly on GitHub Pages.

Design Goals

  • Readable: clear typography, consistent spacing, simple layout.
  • Realistic: character profiles include role, faction, powers, weaknesses, and background.
  • Usable: navigation is consistent on every page and the home search filters instantly.
  • Maintainable: character data is stored in JavaScript arrays for easy updates.

If this were upgraded to a dynamic app later, the same structure could connect to an API and database. For this assignment, the goal is a clean static prototype that looks professional and is easy to navigate.
