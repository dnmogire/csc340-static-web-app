ABOUT THE PROJECT

Static Web Application for CSC 340

Overview

The Manchester United Player Gallery is a static web application prototype developed as part of the CSC 340 course. This project demonstrates fundamental web development skills including HTML5, CSS3, and JavaScript, while showcasing modern design principles and responsive layout techniques.

The application features a curated selection of current Manchester United players, complete with biographical information, statistics, and a powerful search functionality that allows users to filter players by various criteria.

Purpose & Goals

This project serves as a practical demonstration of static web development fundamentals. The goals include:

✓ Creating semantic, accessible HTML5 markup
✓ Implementing responsive CSS layouts with modern techniques
✓ Adding interactive functionality with vanilla JavaScript
✓ Designing an engaging, user-friendly interface
✓ Deploying a static site using GitHub Pages
